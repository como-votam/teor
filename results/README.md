# Resultados publicados

Este diretório não contém avaliações inventadas. Cada arquivo JSON deve seguir o contrato Result, identificar um dataset público e ter previsões reproduzíveis.

Pacotes de submissão ficam em `results/submissions/<id>/` com `items.jsonl`, `predictions.jsonl` e `result.json`, ou referências verificáveis para os artefatos grandes. A CI recalcula os pacotes presentes. Arquivos ocultos de rodadas abertas nunca entram aqui.
