# Uma nota responde a uma pergunta

Um modelo pode contar votos corretamente e errar uma regra constitucional. Somar esses resultados esconde a diferença que interessa a quem vai usá-lo.

## Contexto muda o experimento

Com o registro no prompt, medimos compreensão. Sem o registro, observamos conhecimento e memorização. Com ferramentas, avaliamos também a busca. Compare execuções do mesmo modo.

## Incerteza acompanha a nota

Variantes do mesmo fato não são exemplos independentes. O bootstrap agrupa proposições relacionadas e votações antes de calcular intervalos. Conjuntos com poucas famílias podem produzir intervalos pouco informativos.

## Previsão exige evidência temporal

Uma API consultada hoje pode mostrar informações que não existiam antes da votação. Retirar o placar é necessário, mas não basta para provar uma previsão prospectiva. O Teor registra essa limitação.

## Uma citação pode existir e não sustentar a afirmação

A verificação automática localiza o trecho. Dois revisores independentes avaliam se ele sustenta a afirmação. Sem revisão, a fidelidade semântica permanece sem nota.
