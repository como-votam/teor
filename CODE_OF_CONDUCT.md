# Conduta

Discuta evidência e metodologia com respeito. Não publique ataques pessoais, dados pessoais dispensáveis ou afirmações políticas como se fossem gabaritos factuais.

Mantenedores podem remover conteúdo que viole estas regras e explicar a decisão. Contribuições de boa-fé devem receber uma resposta sobre o problema concreto apresentado.
